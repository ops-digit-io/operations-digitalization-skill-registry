# Template resolution record

Fill once per deliverable. Attach to the deliverable. Procedure: [`../SKILL.md`](../SKILL.md); lookup:
[`../references/master-register.md`](../references/master-register.md).

| Field | Entry |
|---|---|
| Deliverable (one sentence) | ⟨what artefact, for which use case or plant⟩ |
| Lane / step | ⟨Spine, Lane 1 / 2 / 3, step⟩ |
| Prepared by (role) / date | ⟨role, YYYY-MM-DD⟩ |
| Register row matched (section A, B or C) | ⟨row name⟩ |
| Master location (library or report name, as the register gives it) | ⟨location⟩ |
| Owner role | ⟨role⟩ |
| Register version / verified date | ⟨date from the register⟩ |
| Date the master was opened by you | ⟨YYYY-MM-DD⟩ |
| Title and date on the opened file match the register? | ⟨yes / no: if no, describe the difference⟩ |
| Register state | ⟨usable / age flagged / not collected / no master / not registered / conflict⟩ |
| **Outcome** | ⟨use the master / use and flag age / stop and route / route to creation⟩ |
| Who was asked, and when (if outcome is not "use") | ⟨role, date⟩ |
| Parts of the work that proceed without the master | ⟨list or "none"⟩ |
| Source line to put in the deliverable | "Started from ⟨master name⟩ (⟨location⟩, register verified ⟨date⟩)." |
