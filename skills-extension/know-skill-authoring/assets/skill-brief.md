# Skill brief: ⟨skill name⟩

| | |
|---|---|
| Proposed name | ⟨od-object, lowercase, one capability⟩ |
| Owner (a role) | ⟨role⟩ |
| Prepared by / date | ⟨role⟩ · ⟨date⟩ |
| Library | ⟨extension, or core if the process flow draws it⟩ |
| Tier | ⟨foundation / lane / practice / technical⟩ |
| Lane and step | ⟨lane 1 to 4, step id, or "all"⟩ |

## 1. The need

⟨What recurring procedure is this, who does it today, how often, and what goes wrong when it is done without a written method. One paragraph, no solution words.⟩

## 2. Already covered?

⟨The registry search: which skills were checked (README, registry.yaml), what each covers, why a new skill and not an extension of one of them.⟩

## 3. Users and authority

⟨Who uses it (roles). What an agent may do (draft, recommend, execute with approval) and what a human decides. Which decision-rights row applies (`dept-decision-rights`).⟩

## 4. Inputs and output

⟨What the skill needs and what it returns; the format of the output.⟩

## 5. What the agent lacks without the skill

⟨The department-specific steps, corrections, formats and context an agent would get wrong. If the answer is "nothing", stop: no skill is needed.⟩

## 6. Sources opened

| Source | Where | What it supports |
|---|---|---|
| ⟨knowledge base note, archive file, external page⟩ | ⟨path and place⟩ | ⟨the step or rule⟩ |

Order: knowledge base, then archive, then external. Cite only what was opened. Open questions for the owner: ⟨list; each with the person who can answer⟩.
