# Department formats

These formats exist in the department's own material. They are **existing practice to build on, not approved Lane 4 standards**: the January 2026 marketing-template initiative was meant to define a template and a marketing process (interfacing processes, responsibilities, communication channels), but its results slide is empty, it records a lead and no team, and nothing shows it was finished (Deck Texts: `D-Operations Digitalization/OD Initiative - Creation of Marketing Template for Use Cases.md`, slides 2-3, deck dated 2026-01-25). Every source below was opened on 2026-11-10 and is cited by its vault deck text; the originals are in the archive (`Archive: <same path>.pptx`).

## 1. CSP appetizer (plant-side project summary)

The department's template for a short project summary ("CSP | APPETIZER Template", slide 11 of the marketing-template initiative). Fields as written there:

| Field | In a Lane 4 brief |
|---|---|
| Location and region | Plant (not a person) |
| Project title | The use case title |
| Project leader, project sponsor | **Roles only**, never names |
| Project description | The one-sentence message |
| Initial situation; situation after | Before and after, in words |
| Project pictures or screenshots | Screenshots of the screen only; **no people** (see the people-content rule in `od-showcase-selection`) |
| Shopfloor KPI key numbers: KPI before, KPI after | Each with an evidence class and a source |
| Invest or expense, savings, payback (kEUR, months) | Only as **claims** unless a plant savings project and a baseline are registered; never invented |
| Keywords | Tags for the Use Case Library |

## 2. Method, digital standard use case, standard process (marketing pairing)

The initiative pairs an **OPEX standard method**, a **digital standard use case** and a **standard process**, with a "WHAT?" (what the standard process achieves, its impact, which goals it supports) and a "HOW?" (what the combination of method and use case achieves) block, plus a link to a use-case example (slides 4-5). Worked examples named in the deck: types of waste, digital Gemba boards, a switch-off campaign, peak detection (slides 6-9). Use it for the **OPEX and PPI/ME audience**: say which method step the use case supports.

## 3. Plant testimonial

Four key aspects for a testimonial (Deck Texts: `03-AMT_MI_Standard_Agenda_Use_Case_Works/9.0-Marketing_Slides-WIP.md`, slide 17, dated 2025-01-17): highlight the problem (initial state); showcase the solution (digitalization benefits); present the outcome (results achieved); personal input (quote, call for action, recommendation). In Lane 4 the personal input is written as a **role statement** ("the shift lead of line X says ...") and only with the consent or balancing check required by `od-showcase-selection`.

## 4. ODEC story shapes

Two shapes appear in the ODEC deck of 2025-11-19 (Deck Texts: `D-Operations Digitalization/2025 10-ODEC.md`, slides 9-11): **Introduction, story behind, functions and features** (slide 9); and **Process, business impact, digital solution** with the current process, the problem and the potential benefits (slides 10-11).
